# 验收清单

适用于文档评审、素材试制和游戏集成。依据是本项目采用的规范，不是平台认证。

## 记录规则

每项记录：规则ID、构建/素材版本、设备与浏览器、前置状态、操作、预期、实际、证据路径、状态、负责人或后续动作。

- **通过**：已执行相关检查，证据符合预期。
- **失败**：已执行检查，发现可复现的不符。
- **待验证**：缺少素材、实现、设备或测试记录。设计正确不等于运行通过。
- **不适用**：明确排除的玩法/平台，并写原因；未实现但已在需求内的项目不能归为不适用。

严重度：P0数据损坏/不可继续；P1核心操作或一致性错误；P2视觉与体验缺陷。项目可重定义等级，须一致使用。

## 检查矩阵

| ID | 操作或场景 | 通过条件 |
|---|---|---|
| A01 | 同屏放角色、门、树、建筑、UI | 密度、比例、视角、色板、描边与光照符合基准 |
| A02 | 地形内外角、端点、孤立块、窄通道组合 | 所支持连接完整，无缺块和明显接缝 |
| A03 | 按交付元数据导入并切动画帧 | 坐标原点/单位明确；裁切后锚点不跳动 |
| A04 | 绕树、过门、走到建筑后 | 占地、碰撞、交互和前后遮挡符合规则 |
| A05 | 早中晚各观察角色、入口、收藏物 | 目标可识别，夜色不掩盖关键信息 |
| A06 | 核对资源清单与授权 | 来源与使用范围有记录，变体无假占位 |
| W01 | 更改窗口、DPR、浏览器zoom及编辑器zoom | 无重复缩放；指针仍命中正确格子；UI不被裁掉 |
| W02 | 30/60/120Hz或相应模拟、斜向、长帧 | 同时长移动距离按预先声明容差一致，不穿墙 |
| W03 | 按住移动切后台/打开面板/失去焦点 | 不持续卡键、不瞬移、不穿透UI输入 |
| W04 | 编辑、撤销、重做、导出、重新导入 | 内容等价；预览不污染正式存档 |
| W05 | 导入重复ID、悬空引用、未知动作、脚本字段 | 给明确错误；不执行脚本；保留原地图 |
| W06 | 复制/删除被事件引用的对象 | 新实例有新ID；依赖可修复，无静默失效 |
| W07 | 站在事件区、反复进出、双击、刷新读档 | 按重复策略执行；一次性奖励只发一次 |
| W08 | 奖励动作中途失败、保存失败后重试 | 不重复发奖、不吞奖励、不错误显示保存成功 |
| W09 | 精确跨早/中/晚边界、跨日、跳过多个阶段 | phase及边界事件一致；补发策略符合文档 |
| W10 | 后台恢复、暂停/继续、对话期间经过边界 | 按时间策略推进；不漏发或重发关键事件 |
| W11 | 首次收集、重复拾取、消耗、读档、再次领奖 | 背包与收集历史分离；首次奖励幂等 |
| W12 | 旧档迁移、损坏档、存储拒绝、两标签页 | 不静默清空或覆盖；保留恢复路径 |
| W13 | 收集册长中文、字体放大、键盘/触控 | 内容可读、可关闭、焦点正确；不只靠颜色 |
| W14 | 目标设备密集场景连续运行与反复开关面板 | 符合已声明预算；记录帧耗时与内存趋势 |
| W15 | 自由摆放跨格、锚点落边界、切换方向或变体 | 权威坐标无二义性；几何同步更新；重叠失败可回退 |
| W16 | 事件等待跨时段、两个事件同时解锁同一收藏 | 条件重验符合约定；串行提交，首次奖励不重复 |

## 最小集成样板

一段草地到道路及水岸连接、一棵树、一栋带门建筑、一个四方向角色、一个进入区域事件、一个可拾取收藏物、一个收集册页面和可切换的早中晚。

贯通流程：编辑器摆放 → 运行预览 → 行走与遮挡 → 进入区域 → 满足时段条件 → 获取收藏 → 收集册更新 → 保存 → 刷新读档 → 不重复发奖。再验证撤销/重做与切后台。

没有实际游戏时只交付此测试方案，全部运行项保持待验证。本Skill文档的校验和应用测试不能替代该游戏的浏览器测试。

## 量产门槛

代表资产完成A01–A04后，再扩大同类资产生产；系统开发按已验证的数据合同并行推进。P0/P1问题需处理后才能声称对应流程可发布；无影响的工作不必整体停摆。
